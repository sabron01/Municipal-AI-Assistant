# Contribuer

1. Lire `AGENTS.md` et le profil concerné.
2. Travailler dans une branche dédiée.
3. Limiter le changement au ticket / sprint autorisé.
4. Ajouter ou mettre à jour les tests.
5. Documenter les décisions et les limites.
6. Fournir les commandes exécutées et leurs résultats réels dans la PR.
7. Ne jamais inclure `.env`, secrets, documents municipaux réels ou données personnelles dans les commits.

Convention proposée : commits courts et explicites (`docs:`, `feat:`, `fix:`, `test:`, `chore:`). À confirmer avec l'équipe.
