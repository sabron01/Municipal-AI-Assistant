# ADR-001 — Monorepo

- Statut : accepté.
- Décision : regrouper backend, frontend, infrastructure, MCP et documentation dans un dépôt unique.
- Motif : simplifier la coordination, les contrats et la livraison initiale.
- Conséquences : conventions communes ; pipelines pouvant cibler les sous-projets ; attention aux dépendances et droits d'accès.
