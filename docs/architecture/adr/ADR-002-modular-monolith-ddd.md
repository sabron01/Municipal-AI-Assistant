# ADR-002 — Monolithe modulaire DDD

- Statut : accepté.
- Décision : application déployable comme un monolithe modulaire, structurée par domaines et couches Clean Architecture.
- Motif : limiter la complexité opérationnelle initiale tout en préservant les frontières métier.
- Conséquences : pas de microservices au Sprint 0 ; contrats internes explicites ; extraction ultérieure éventuelle sur décision documentée.
