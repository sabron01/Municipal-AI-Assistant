# ADR-004 — Formats documentaires et OCR

- Statut : accepté pour le périmètre cible.
- Décision : prendre en charge PDF, documents Office et images ; prévoir OCR pour les contenus scannés ou image.
- À préciser : extensions exactes, taille maximale, langues, qualité minimale, extraction tableaux et traitement des fichiers protégés.
- Conséquence : construire un benchmark français/arabe avant de figer la chaîne technique.
