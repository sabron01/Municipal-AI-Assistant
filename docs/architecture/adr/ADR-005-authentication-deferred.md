# ADR-005 — Authentification différée

- Statut : différé.
- Décision : aucune technologie ni modèle d'identité n'est sélectionné au Sprint 0.
- Condition : définir les populations, rôles, périmètres d'accès, annuaire éventuel, SSO et exigences de sécurité avant implémentation.
- Garde-fou : aucune fonctionnalité documentaire ne doit être exposée en production sans contrôle d'accès validé.
