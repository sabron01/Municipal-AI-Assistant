# ADR-007 — Sélection des modèles après benchmark

- Statut : différé.
- Décision : ne pas figer les modèles LLM ou embeddings avant une évaluation comparative.
- Critères à mesurer : qualité français/arabe, latence, consommation mémoire/VRAM, fonctionnement CPU/GPU, confidentialité, licence et facilité d'exploitation locale.
