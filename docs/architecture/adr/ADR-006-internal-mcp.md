# ADR-006 — MCP interne uniquement

- Statut : accepté.
- Décision : les serveurs MCP exposent uniquement des outils internes au système municipal.
- Garde-fous : liste blanche d'outils, validation des paramètres, moindre privilège, journalisation et approbation humaine pour toute action à impact.
- Aucun accès public ou outil externe n'est autorisé par cette décision.
